## Installation and use

For Microsoft 365 Copilot Chat, download a skill’s SKILL.md and use Upload skill where available. For Claude, put SKILL.md in a folder matching its name, ZIP that folder, then upload through Skills. Other hosts have their own installation requirements. Publication here does not automatically install or update skills.

These standalone instruction-only skills require no scripts, network calls or credentials. Format and catalogue checks have passed; runtime behaviour in Copilot and Claude has not been verified. Test with representative evidence, missing inputs and contradictory material before relying on results. Retain competent review and authorisation for engineering, safety and operational decisions.
