# Work Prompt Studio skills

Source site: [workprompts.jp226.com](https://workprompts.jp226.com)

Version **2026.11.01** — 58 general engineering consultancy workflows. Cybersecurity workflows are excluded from public skills. The blank brief remains a prompt-building option.

Use the website for personalised one-off prompts; install a skill for a repeated workflow. Each folder contains a standalone SKILL.md. These are instruction-only skills, with no scripts, network calls or credentials. Source-format and catalogue checks have passed; runtime behaviour in Copilot and Claude has not been verified.

## Install

- Microsoft 365 Copilot Chat: download a skill's SKILL.md and use Upload skill where enabled by your organisation. This does not install a declarative agent.
- Claude: put SKILL.md in a folder matching its name, ZIP that folder, then upload through Skills.
- Other Agent Skills hosts: follow the host's installation instructions and available tool permissions.

Publication on GitHub does not automatically install or update skills in an AI service. Review output against approved source material before use.

## Validation cases

For each installed skill test a representative complete brief, missing source material, contradictory evidence and an unavailable tool or attachment. Confirm it identifies limits and does not invent facts, approvals or results. For signalling, safety and operational outputs, retain the required competent review and authorisation.
