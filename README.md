# JP226Prints Skills

These skills are free to use. A good cause, if you choose: if they help you, please consider a voluntary donation to our Variety fundraising team. Donations are entirely optional and do not unlock anything.

**[Donate to The Fast and the Fossilized](https://www.variety4wdqld.com.au/t/thefastandthefossilized)**

## How to use a skill

Each skill is a folder with a `SKILL.md` file at its top level, plus a README with examples. To add one to Claude, zip the skill folder (keep the folder itself inside the zip) and add it as a skill. Then ask Claude for the task the skill covers, or type the skill's name as a command, for example `/jp226-website-builder`.

## Versions

Every skill follows the `vx.xx` version pattern and keeps a `HISTORY.md` of changes. Skills are created by JP226Prints.
