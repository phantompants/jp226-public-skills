# JP226 Public Skills

Reusable, general-purpose AI skills from JP226 websites.

## Work Prompt Studio

[Browse 58 engineering consultancy skills by work type](workprompts-jp226-com/README.md). Each engineering filter has its own folder and skills subfolder. Cybersecurity workflows are excluded from the public collection.

Use [Work Prompt Studio](https://workprompts.jp226.com) to build personalised prompts, or use the skill versions for repeated workflows. Supply project material only within your approved AI environment. Installation and runtime support depend on the target tool.

Earlier JP226 skills are also organised in [phantompants/AI/Skills](https://github.com/phantompants/AI/tree/main/Skills). Other existing folders in this repository are retained.
